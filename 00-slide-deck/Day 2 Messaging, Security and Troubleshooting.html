Module 11 · JWT · Build one by hand

A JWT is just three commands

# ~/lab/make-jwt.sh   usage: ./make-jwt.sh <seconds-valid> [aud]
SECRET="paybank-lab-secret-do-not-reuse-1"
b64url() { openssl base64 -A | tr "+/" "-_" | tr -d "="; }
now=$(date +%s)
header='{"alg":"HS256","typ":"JWT"}'
payload="{\"iss\":\"https://auth.example.com\",\"sub\":\"mobile-app\","
payload+="\"aud\":\"${2:-payment-api}\",\"iat\":$now,\"exp\":$((now + $1))}"
h=$(printf "%s" "$header"  | b64url)
p=$(printf "%s" "$payload" | b64url)
s=$(printf "%s" "$h.$p" | openssl dgst -sha256 -hmac "$SECRET" -binary | b64url)
echo "$h.$p.$s"

Day 2 · Wrap-up · Knowledge check · 1 of 2

Can you answer these?

a

The API returns 202 but no SMS arrives. Where do you look first?

The broker: messages_ready, unacked and sms.dlq; Kafka consumer lag

b

LAG keeps growing on one partition only. What is likely?

A hot key, or the one consumer for that partition is stuck

c

Kong says 401 for a token that worked an hour ago. Why?

exp has passed (or the clocks disagree): check exp, then timedatectl

d

curl says “unable to get local issuer certificate”. What is missing?

The intermediate certificate in the server’s chain (or the CA in the trust store)
